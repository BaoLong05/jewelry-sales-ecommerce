## 📌 Giới thiệu

Jewelry Sales E-commerce Website là hệ thống website bán trang sức trực tuyến, hỗ trợ người dùng xem sản phẩm, thêm sản phẩm vào giỏ hàng, thanh toán và quản lý đơn hàng.

Hệ thống được phát triển theo mô hình tách biệt Backend và Frontend:

- Backend: Laravel 12
- Frontend: ReactJS
- Database: MySQL
- Environment: Docker + Vagrant + VirtualBox

# 🚀 Công nghệ sử dụng

| Công nghệ | Mô tả |
|---|---|
| Laravel 12 | Xây dựng Backend API |
| ReactJS | Xây dựng giao diện người dùng |
| MySQL | Lưu trữ dữ liệu |
| Docker | Tạo môi trường chạy project |
| Vagrant | Quản lý máy ảo |
| VirtualBox | Ảo hóa môi trường |
| Nginx | Web Server |
| Cloudflare Pages | Deploy Frontend Production |
